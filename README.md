# 🆕 New C# File – VS Code Extension

Easily create new C# class, interface, record, struct, or enum files with modern syntax and correct namespaces – right from the Explorer context menu.

---

## ✨ Features

- Adds a **"New C# File"** option to the Explorer folder context menu
- Prompts you to choose the C# type:
  - `class`, `interface`, `record`, `struct`, or `enum`
- Prompts for the name of the new type
- Uses **file-scoped namespaces** (C# 10 / .NET 6+)
- Automatically generates the correct namespace based on the folder structure
- Opens the new file in the editor, ready to code 💻

---

## 📦 Installation

From the VS Code Marketplace:

1. Go to the Extensions tab in VS Code
2. Search for: **New C# File**
3. Click **Install**

Or install from the terminal:

```bash
code --install-extension your-publisher-id.new-cs-file
